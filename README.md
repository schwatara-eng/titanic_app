## 🏆 퀴즈 — 생존율 1위와 생존자 수 1위는 같을까?

성별 × 객실 등급, 6개 집단을 두 기준으로 줄 세워 본다.

| 집단 | 생존 / 전체 | 생존율 |
| :--- | ---: | ---: |
| 1등급 여성 | 91 / 94명 | 96.8% |
| 2등급 여성 | 70 / 76명 | 92.1% |
| 3등급 여성 | 72 / 144명 | 50.0% |
| 1등급 남성 | 45 / 122명 | 36.9% |
| 2등급 남성 | 17 / 108명 | 15.7% |
| 3등급 남성 | 47 / 347명 | 13.5% |

<details>
<summary><b>답 확인하기</b></summary>

<br>

**같다.** 생존율도, 생존자 수도 **1등급 여성**이 1위.
다만 2위부터는 달라진다 — 생존율 2위는 2등급 여성(92.1%), 생존자 수 2위는 3등급 여성(72명).

</details>

## 🤖 모델로 생존 여부 예측하기

승객 정보 4가지를 넣고 **예측하기**를 누르면

| 입력 | 예시 기본값 |
| --- | --- |
| 나이 | 22 |
| 성별 | 남성 / 여성 |
| 객실 등급 | 1 · 2 · 3등급 |
| 요금 | 7.25 |

→ 학습 모델(`titanic_model.pkl`)이 **생존 / 사망**을 예측해 보여 준다.

> 예측은 학습한 데이터의 경향일 뿐, 실제 개인의 운명을 말하지 않는다.

## ▶️ 실행하기

**1. 패키지 설치**

```bash
python -m pip install streamlit pandas joblib scikit-learn
```

**2. 앱 실행**

```bash
python -m streamlit run app.py
```

**3.** 터미널에 뜬 **Local URL**을 브라우저에서 열기

> ⚙️ 모델을 불러올 때 버전 오류가 나면, 모델을 만든 환경과 **같은 scikit-learn 버전**을 설치한다.
